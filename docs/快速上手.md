# MindCtx 快速上手

## 选择你的平台

MindCtx 支持 Obsidian 和 VS Code 两个平台。核心功能一致，操作方式略有不同。

| | Obsidian | VS Code |
|--|----------|---------|
| 命令面板 | Ctrl/Cmd+P | Ctrl/Cmd+Shift+P |
| 安装方式 | 社区插件 | 扩展商店 |
| 撤销/重做 | 插件内管理 | VS Code 原生 |
| 嵌入块 | 支持 | — |

---

## 5 分钟入门

### 第一步：创建文件

**Obsidian**：打开命令面板（Ctrl/Cmd+P），输入 `MindCtx: 创建 MindCtx 文件`。

**VS Code**：打开命令面板（Ctrl/Cmd+Shift+P），输入 `MindCtx: Create New File`。

两种方式都会自动生成一个 `.mind.md` 文件并打开 MindCtx 视图。

也可以手动创建任意 `.mind.md` 文件，内容如下：

```markdown
---
mindctx: true
---

# 我的第一个大纲

## 主题一

## 主题二
```

### 第二步：编辑节点

- **双击**节点标题进入编辑模式
- **Enter** 确认编辑
- **Escape** 取消编辑

### 第三步：组织结构

- 按 **Enter** 在选中节点下方创建新的兄弟节点
- 按 **Tab** 将节点缩进为上一个兄弟的子节点
- 按 **Shift+Tab** 将节点提升一级
- **拖拽**节点到目标位置（上方/下方/内部）

### 第四步：切换视图

**Obsidian**：点击工具栏「脑图」按钮，或命令面板「MindCtx: 切换视图」。

**VS Code**：点击工具栏图标，或按 Cmd/Ctrl+Shift+M，或命令面板「MindCtx: Toggle View」。

## 核心概念

### Markdown 就是数据

MindCtx 不使用专有格式。你的大纲数据始终是标准 Markdown：

- `# 标题` → 树的分支节点
- `- 列表项` → 树的叶节点
- 标题下的段落 → 节点的「备注」
- 代码块/引用块 → 节点的「附属内容」

这意味着：
- 其他 Markdown 编辑器可以正常打开你的文件
- Git diff 可以清晰显示结构变更
- 你不会被锁定在任何工具中

### heading-depth 参数

`heading-depth` 控制「标题」和「列表项」的分界线：

```markdown
---
heading-depth: 3
---
```

- 深度 1-3 的节点输出为 `#`、`##`、`###` 标题
- 深度 4+ 的节点输出为缩进的列表项

示例：当 `heading-depth: 2` 时：

```
根节点          → # 根节点
├── 子节点 A    → ## 子节点 A
│   ├── 孙节点  → - 孙节点       （深度 3 > heading-depth 2，变成列表）
│   │   └── 曾孙  → - 曾孙       （缩进列表）
```

### 往返保真

MindCtx 的核心设计原则：**不修改的内容保持原样**。

即使你的 Markdown 有不规范的空行、缩进或格式，只要你没有通过 MindCtx 编辑那个节点，序列化回文件时这些内容会原样保留。只有被编辑的节点才会被重新生成。

## 日常工作流

### 会议记录

1. 会前用 MindCtx 列出议程（脑图视图做全局规划）
2. 会中切换到大纲视图逐条记录
3. 会后拖拽调整结构，整理行动项（添加 `- [ ]` 任务）

### 知识整理

1. 阅读时随手记录关键点
2. 用 Tab/Shift+Tab 调整层级关系
3. 用脑图视图检查整体结构是否合理
4. 导出为 AI 上下文，让 AI 帮助补充细节

### 项目规划

1. 用脑图视图做头脑风暴（自由添加节点）
2. 切换到大纲视图精细化排列
3. 添加任务复选框标记里程碑
