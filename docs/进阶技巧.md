# MindDoc 进阶技巧

## 高效编辑技巧

### 批量创建节点

按住 Enter 连续创建多个空节点，然后逐个输入标题。比反复在「添加」和「编辑」之间切换更快。

### 快速重组结构

1. 先在大纲中自由罗列所有想法（不管层级）
2. 然后用 Tab/Shift+Tab 批量调整层级
3. 用 Ctrl+↑/↓ 调整顺序

这比一开始就规划好层级更高效——先发散，后收敛。

### 利用脑图做全局审视

当你在大纲中编辑了很长一段时间后，切换到脑图视图可以快速看到整体结构是否均衡。如果某个分支明显过大，考虑拆分为独立文件。

### 键盘流操作

完全不用鼠标的操作流程：
1. ↑/↓ 导航到目标节点
2. Enter 创建新节点，直接输入标题
3. Tab 调整层级
4. Ctrl+↑/↓ 调整位置
5. F2 修改已有节点

## 与其他 Obsidian 功能配合

### 双向链接

在节点标题中使用 `[[链接]]` 语法：

```markdown
## 技术选型

- [[React]] vs [[Vue]] 对比
- 选择 [[Next.js]] 框架
```

在 Obsidian 的图谱视图中可以看到这些关联。

### 标签系统

在标题中使用 `#标签`：

```markdown
## 紧急任务 #urgent

- 修复登录 bug #frontend
- 数据库迁移 #backend
```

MindDoc 会自动提取标签到节点的 `tags` 字段。

### 嵌入到 MOC（Maps of Content）

在你的 MOC 笔记中嵌入 MindDoc 视图：

````markdown
# 项目管理 MOC

## 当前项目概览

```minddoc
file: [[2024-Q1 项目规划.mind.md]]
mode: mindmap
height: 300
maxDepth: 2
```

## 相关笔记

- [[项目管理方法论]]
- [[敏捷开发实践]]
````

### 模板

创建一个 MindDoc 模板文件供快速使用：

```markdown
---
minddoc: true
default-view: outline
heading-depth: 3
---

# {{title}}

## 背景

- 

## 目标

- 

## 方案

### 方案 A

- 

### 方案 B

- 

## 行动项

- [ ] 
```

## 大文件处理策略

### 何时拆分

当一个文件超过 200 个节点时，考虑拆分：

- 每个大章节独立成文件
- 用嵌入块在总览页引用各子文件
- 保持单个文件在 50-150 节点之间最舒适

### 性能优化设置

对于大文件：
- 开启虚拟滚动（设置中默认已开启）
- 使用搜索快速定位，避免全文滚动
- 脑图视图设置 maxDepth 限制渲染深度

## AI 协作工作流

### 用 AI 扩写大纲

1. 先手动写出顶层结构（2-3 层）
2. 使用「复制为 AI 上下文」命令
3. 粘贴给 AI，要求扩写某个分支
4. 将 AI 的输出粘贴回 Markdown 文件
5. MindDoc 自动解析新内容

### 用 AI 做内容审查

1. 复制为 AI 上下文
2. 让 AI 检查：
   - 逻辑是否自洽
   - 是否有遗漏的维度
   - 层级是否合理
3. 根据 AI 建议在 MindDoc 中调整结构

### 提示词模板

```
以下是我的文档结构，请帮我：
1. 检查是否有遗漏的重要维度
2. 指出层级组织不合理的地方
3. 建议可以合并或拆分的节点

[粘贴 AI 上下文]
```

## 数据备份与迁移

### 备份

MindDoc 的数据就是 Markdown 文件，跟随 Obsidian vault 一起备份即可：
- Git 同步
- iCloud / OneDrive / Dropbox
- 定期 zip 打包

### 迁移到其他工具

- **导出 OPML** → 导入到幕布、WorkFlowy、OmniOutliner
- **导出 JSON** → 自定义脚本处理
- **直接编辑**：文件本身就是 Markdown，任何工具都能打开

### 从其他工具迁移过来

| 来源 | 方法 |
|------|------|
| 幕布 | 导出 OPML → MindDoc 导入 |
| WorkFlowy | 导出 OPML → MindDoc 导入 |
| FreeMind / XMind | 导出 .mm → MindDoc 导入 |
| Notion | 导出 Markdown → 添加 frontmatter |
| 纯 Markdown | 添加 `minddoc: true` frontmatter 即可 |

## 自定义样式

MindDoc 使用 Obsidian CSS 变量，你可以通过 CSS snippet 自定义外观：

```css
/* .obsidian/snippets/minddoc-custom.css */

/* 调整节点行高 */
.minddoc-node {
  height: 36px;
}

/* 自定义高亮颜色 */
.minddoc-highlight {
  background: rgba(100, 200, 255, 0.3);
}

/* 隐藏备注预览 */
.minddoc-note-preview {
  display: none;
}

/* 脑图根节点样式 */
.minddoc-mindmap-container me-root {
  font-size: 20px;
  font-weight: 700;
}
```

在 Obsidian 设置 → 外观 → CSS 代码片段中启用即可。
