# MindDoc 进阶技巧

## 高效编辑技巧

### 批量创建节点

按住 Enter 连续创建多个空节点，然后逐个输入标题。比反复在「添加」和「编辑」之间切换更快。

### 快速重组结构

1. 先在大纲中自由罗列所有想法（不管层级）
2. 然后用 Tab/Shift+Tab 批量调整层级
3. 用 Ctrl+↑/↓ 调整顺序

这比一开始就规划好层级更高效——先发散，后收敛。

### 利用脑图做全局审视

当你在大纲中编辑了很长一段时间后，切换到脑图视图可以快速看到整体结构是否均衡。如果某个分支明显过大，考虑拆分为独立文件。

### 键盘流操作

完全不用鼠标的操作流程：
1. ↑/↓ 导航到目标节点
2. Enter 创建新节点，直接输入标题
3. Tab 调整层级
4. Ctrl+↑/↓ 调整位置
5. F2 修改已有节点

## 平台特有功能

### Obsidian 专属

**双向链接**：在节点标题中使用 `[[链接]]` 语法，在 Obsidian 图谱视图中可以看到关联。

**标签系统**：在标题中使用 `#标签`，MindDoc 会自动提取到节点的 `tags` 字段。

**嵌入到 MOC**：在 Maps of Content 笔记中嵌入 MindDoc 视图展示项目结构。

**模板**：创建 MindDoc 模板文件，配合 Obsidian 模板插件快速使用。

### VS Code 专属

**多编辑器同步**：同一个 `.mind.md` 文件可以在多个编辑器标签页打开，编辑实时同步（peer edit）。

**原生撤销栈**：撤销/重做由 VS Code 统一管理，与文件编辑历史一致。

**工作区设置**：在 `.vscode/settings.json` 中为项目配置 MindDoc 默认值：

```json
{
  "minddoc.defaultView": "mindmap",
  "minddoc.headingDepth": 2,
  "minddoc.mindmapDirection": "right"
}
```

**自定义快捷键**：在 VS Code Keyboard Shortcuts 中重新绑定所有 MindDoc 命令。

**外部文件变更检测**：git pull 或外部编辑器修改文件后，MindDoc 自动检测并刷新。

## 大文件处理策略

### 何时拆分

当一个文件超过 200 个节点时，考虑拆分：

- 每个大章节独立成文件
- 保持单个文件在 50-150 节点之间最舒适

### 性能优化

- 脑图视图在节点多时可能有渲染延迟，使用大纲视图编辑更流畅
- 使用搜索（Ctrl+F）快速定位，避免全文滚动

## AI 协作工作流

### 用 AI 扩写大纲

1. 先手动写出顶层结构（2-3 层）
2. 使用「复制为 AI 上下文」命令
3. 粘贴给 AI，要求扩写某个分支
4. 将 AI 的输出粘贴回 Markdown 文件
5. MindDoc 自动解析新内容

### 用 AI 做内容审查

1. 复制为 AI 上下文
2. 让 AI 检查：
   - 逻辑是否自洽
   - 是否有遗漏的维度
   - 层级是否合理
3. 根据 AI 建议在 MindDoc 中调整结构

### 提示词模板

```
以下是文档 "项目规划" 的结构化内容：

[粘贴 AI 上下文]

请帮我：
1. 检查是否有遗漏的重要维度
2. 指出层级组织不合理的地方
3. 建议可以合并或拆分的节点
```

## 数据备份与迁移

### 备份

MindDoc 的数据就是 Markdown 文件，跟随项目/vault 一起备份：
- Git 同步（推荐）
- 云存储（iCloud / OneDrive / Dropbox）

### 迁移到其他工具

- **导出 OPML** → 导入到幕布、WorkFlowy、OmniOutliner
- **导出 JSON** → 自定义脚本处理
- **直接编辑**：文件本身就是 Markdown，任何工具都能打开

### 从其他工具迁移过来

| 来源 | 方法 |
|------|------|
| 幕布 | 导出 OPML → MindDoc 导入 |
| WorkFlowy | 导出 OPML → MindDoc 导入 |
| FreeMind / XMind | 导出 .mm → MindDoc 导入 |
| Notion | 导出 Markdown → 添加 frontmatter |
| 纯 Markdown | 添加 `minddoc: true` frontmatter 即可 |

## 自定义样式

### Obsidian

通过 CSS snippet 自定义外观（设置 → 外观 → CSS 代码片段）：

```css
/* .obsidian/snippets/minddoc-custom.css */

.minddoc-node { height: 36px; }
.minddoc-highlight { background: rgba(100, 200, 255, 0.3); }
.minddoc-note-preview { display: none; }

/* 脑图根节点 */
.minddoc-mindmap-container me-root {
  font-size: 20px;
  font-weight: 700;
}
```

### VS Code

VS Code 的 MindDoc webview 使用 `--vscode-*` CSS 变量适配主题。如需进一步自定义，可以在用户设置中调整相关配色：

- `workbench.colorCustomizations` 中修改 `list.hoverBackground`、`focusBorder` 等变量会影响 MindDoc 外观
- 脑图配色从当前 Color Theme 的前景/背景/accent 色自动推导
