# MindDoc 完整功能指南

## 大纲视图

### 节点操作

| 操作 | 方式 |
|------|------|
| 选中节点 | 单击 |
| 编辑标题 | 双击 或 F2 |
| 确认编辑 | Enter |
| 取消编辑 | Escape |
| 创建兄弟节点 | Enter（选中状态） |
| 创建子节点 | 右键 → 添加子节点 |
| 删除节点 | Delete 或 Backspace |
| 缩进 | Tab |
| 提升 | Shift+Tab |
| 上移 | Ctrl+↑ |
| 下移 | Ctrl+↓ |
| 折叠/展开 | 点击箭头 |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Shift+Z |

### 拖拽排序

拖拽节点时有三种放置位置：

- **上方**（节点上 1/4 区域）：放在目标节点前面
- **下方**（节点下 1/4 区域）：放在目标节点后面
- **内部**（节点中间区域）：成为目标节点的子节点

放置指示器会以蓝色线条/高亮显示当前放置位置。

### 搜索筛选

按 **Ctrl+F** 打开搜索栏：

- 实时筛选：只显示匹配的节点和它们的祖先
- 匹配高亮：关键词会以黄色背景标记
- 按 **Escape** 关闭搜索并恢复全部显示

### 节点详情面板

选中节点后，大纲下方会显示详情面板：

- **备注区**：编辑该节点的描述文本（对应 Markdown 中紧跟标题/列表项的段落）
- **附属内容**：只读展示该节点包含的代码块、引用块、表格等

备注在失焦时自动保存。

### 右键菜单

右键点击任意节点可以：

- 编辑标题
- 添加子节点 / 兄弟节点
- 缩进 / 提升
- 上移 / 下移
- 删除

## 脑图视图

### 基本交互

- **拖拽节点**：移动到新位置（成为其他节点的子节点或兄弟节点）
- **双击节点**：编辑标题
- **滚轮**：缩放
- **拖拽空白区域**：平移画布

### 快捷键

| 按键 | 功能 |
|------|------|
| Tab | 为选中节点添加子节点 |
| Enter | 添加兄弟节点 |
| Delete / Backspace | 删除选中节点 |
| F2 | 编辑节点标题 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |

### 缩放控制

- Ctrl+滚轮 缩放
- 百分比显示 + 滑块精确调节
- 居中按钮快速定位根节点

### 布局方向

在设置中可以调整脑图布局方向：

- **左右展开**（默认）：根节点居中，子节点向两侧交替分布
- **仅向右**：所有节点向右展开
- **仅向左**：所有节点向左展开

### 主题适配

脑图颜色会自动跟随编辑器的当前主题：

- **Obsidian**：从 CSS 变量 (`--background-modifier-*`) 派生
- **VS Code**：从编辑器 Color Theme（light/dark/high-contrast）派生

切换主题时，脑图会实时更新配色。

## 嵌入块 <sup>Obsidian 专属</sup>

在任意 Obsidian 笔记中嵌入 MindDoc 视图：

````markdown
```minddoc
file: [[我的大纲.mind.md]]
mode: switchable
height: 450
default: outline
collapsed: false
maxDepth: 4
```
````

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| file | 是 | - | 目标文件，支持 `[[link]]` 或相对路径 |
| mode | 否 | switchable | `outline` / `mindmap` / `switchable` |
| height | 否 | 400 | 嵌入块高度（px） |
| default | 否 | outline | 初始显示的视图 |
| collapsed | 否 | false | 是否初始折叠所有节点 |
| maxDepth | 否 | 无限 | 最大显示深度 |

### 嵌入块功能

- **视图切换**：mode 为 switchable 时可在大纲/脑图间切换
- **刷新**：点击 ↻ 按钮重新加载文件内容
- **打开**：在新标签页打开完整的 MindDoc 编辑视图
- 嵌入块是**只读**的，不支持编辑操作

## 导入

### 从幕布/WorkFlowy 导入

1. 在源工具中导出为 OPML 格式
2. 执行导入命令：
   - **Obsidian**：命令面板 → 「MindDoc: 导入 OPML 文件」
   - **VS Code**：命令面板 → "MindDoc: Import OPML"
3. 选择导出的 .opml 文件
4. 自动生成 .mind.md 文件并打开

### 从 FreeMind 导入

1. 将 .mm 文件保存到本地
2. 执行导入 FreeMind 命令
3. 选择 .mm 文件

### 导入注意事项

- 导入时 `heading-depth` 默认为 3
- 单根节点的 OPML 会将根作为文件标题
- 多根节点的 OPML 每个顶级节点成为 H2
- OPML 中的 `_note` 属性会保留为节点备注

## 导出

### OPML 导出

导出为 OPML 格式，可被幕布、WorkFlowy 等工具导入。

- **Obsidian**：「MindDoc: 导出为 OPML」
- **VS Code**："MindDoc: Export as OPML"

### JSON 导出

输出简化的树结构 JSON：

```json
{
  "version": 1,
  "root": {
    "title": "根节点",
    "children": [
      { "title": "子节点", "note": "备注文本" }
    ]
  }
}
```

### PNG 导出

在**脑图视图**下导出当前脑图为 2x 分辨率 PNG 图片。

- **Obsidian**：「MindDoc: 导出为 PNG」
- **VS Code**："MindDoc: Export as PNG"

### 复制为 AI 上下文

将当前文档结构化输出到剪贴板，格式适合直接粘贴给 ChatGPT / Claude 等 AI 工具。

## 设置

两个平台的设置项一致，配置方式不同：

- **Obsidian**：设置 → 第三方插件 → MindDoc
- **VS Code**：设置 (Ctrl+,) → 搜索 "minddoc"

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 默认视图 | 大纲 | 打开文件时的默认视图 |
| 默认标题深度 | 3 | heading-depth 全局默认值 |
| 自动保存延迟 | 300ms | 编辑后写入文件的防抖延迟 |
| 大纲字体大小 | 14px | 大纲视图字体大小 |
| 显示备注预览 | 开启 | 在节点标题旁显示 note 首行 |
| 脑图方向 | 左右展开 | 思维导图展开方向 |

> 文件内的 frontmatter `heading-depth` 字段会覆盖全局设置。

## 文件格式详解

### Frontmatter 字段

```yaml
---
minddoc: true              # 标识为 MindDoc 文件（必需，或使用 .mind.md 后缀）
version: 1                 # 格式版本
default-view: outline      # 打开时的默认视图（outline / mindmap）
heading-depth: 3           # 标题最大深度
---
```

### 节点类型映射

| Markdown 元素 | MindDoc 节点类型 | 说明 |
|---------------|-----------------|------|
| `# 标题` | heading 节点 | 深度由 # 数量决定 |
| `- 列表项` | list-item 节点 | 深度由缩进决定 |
| `1. 有序列表` | list-item (ordered) | 标记为有序 |
| `- [ ] 任务` | list-item (checked=false) | 未完成任务 |
| `- [x] 任务` | list-item (checked=true) | 已完成任务 |
| 段落文本 | node.note | 归属为最近节点的备注 |
| 代码块/引用/表格 | node.blocks | 归属为最近节点的附属内容 |

## 常见问题

### Q: 文件可以用其他编辑器打开吗？

可以。MindDoc 文件就是标准 Markdown，任何编辑器都能正常读取和编辑。

### Q: 编辑后会改变我的文件格式吗？

只有你通过 MindDoc 编辑的节点会被重新生成格式。未触碰的内容保持原样。

### Q: 脑图中拖拽节点，大纲会同步吗？

是的。两个视图共享同一棵 AST，任何编辑操作都会实时同步。

### Q: VS Code 的撤销和 Obsidian 有什么不同？

VS Code 版本的撤销/重做通过 VS Code 原生 undo stack 管理，与编辑器其他操作统一。Obsidian 版本有自己的撤销管理器。

### Q: 文件很大时会卡吗？

MindDoc 对 5000+ 行的文件解析时间 < 500ms。大纲视图支持虚拟滚动（Obsidian 版）。脑图视图在 500+ 节点时可能出现渲染延迟。

### Q: 如何与 Git 配合使用？

非常适合。数据是纯文本 Markdown，Git diff 清晰显示每次修改了哪些节点。
