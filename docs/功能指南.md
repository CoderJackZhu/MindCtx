# MindDoc 完整功能指南

## 大纲视图

### 节点操作

| 操作 | 方式 |
|------|------|
| 选中节点 | 单击 |
| 编辑标题 | 双击 或 F2 |
| 确认编辑 | Enter |
| 取消编辑 | Escape |
| 创建兄弟节点 | Enter（选中状态） |
| 创建子节点 | 右键 → 添加子节点 |
| 删除节点 | Delete 或 Backspace |
| 缩进 | Tab |
| 提升 | Shift+Tab |
| 上移 | Ctrl+↑ |
| 下移 | Ctrl+↓ |
| 折叠/展开 | 点击箭头 或 Ctrl+Shift+. |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Shift+Z |

### 拖拽排序

拖拽节点时有三种放置位置：

- **上方**（节点上 1/4 区域）：放在目标节点前面
- **下方**（节点下 1/4 区域）：放在目标节点后面
- **内部**（节点中间区域）：成为目标节点的子节点

放置指示器会以蓝色线条/高亮显示当前放置位置。

### 搜索筛选

按 **Ctrl+F** 打开搜索栏：

- 实时筛选：只显示匹配的节点和它们的祖先
- 匹配高亮：关键词会以黄色背景标记
- 按 **Escape** 关闭搜索并恢复全部显示

### 节点详情面板

选中节点后，大纲下方会显示详情面板：

- **备注区**：编辑该节点的描述文本（对应 Markdown 中紧跟标题/列表项的段落）
- **附属内容**：只读展示该节点包含的代码块、引用块、表格等

备注在失焦时自动保存。

### 右键菜单

右键点击任意节点可以：

- 编辑标题
- 添加子节点 / 兄弟节点
- 缩进 / 提升
- 上移 / 下移
- 删除
- 复制为 Markdown（复制该节点及其子树的 Markdown 文本）

## 脑图视图

### 基本交互

- **拖拽节点**：移动到新位置（成为其他节点的子节点或兄弟节点）
- **双击节点**：编辑标题
- **滚轮**：缩放
- **拖拽空白区域**：平移画布

### 快捷键

| 按键 | 功能 |
|------|------|
| Tab | 为选中节点添加子节点 |
| Enter | 添加兄弟节点 |
| Delete / Backspace | 删除选中节点 |
| F2 | 编辑节点标题 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |

### 布局方向

在设置中可以调整脑图布局方向：

- **左右展开**（默认）：根节点居中，子节点向两侧交替分布
- **仅向右**：所有节点向右展开
- **仅向左**：所有节点向左展开

### 主题适配

脑图颜色会自动跟随 Obsidian 的当前主题（亮色/暗色）。切换 Obsidian 主题时，脑图会实时更新配色。

## 嵌入块

在任意 Obsidian 笔记中嵌入 MindDoc 视图：

````markdown
```minddoc
file: [[我的大纲.mind.md]]
mode: switchable
height: 450
default: outline
collapsed: false
maxDepth: 4
```
````

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| file | 是 | - | 目标文件，支持 `[[link]]` 或相对路径 |
| mode | 否 | switchable | `outline` / `mindmap` / `switchable` |
| height | 否 | 400 | 嵌入块高度（px） |
| default | 否 | outline | 初始显示的视图 |
| collapsed | 否 | false | 是否初始折叠所有节点 |
| maxDepth | 否 | 无限 | 最大显示深度 |

### 嵌入块功能

- **视图切换**：mode 为 switchable 时可在大纲/脑图间切换
- **刷新**：点击 ↻ 按钮重新加载文件内容
- **打开**：在新标签页打开完整的 MindDoc 编辑视图
- 嵌入块是**只读**的，不支持编辑操作

### 使用场景

- 在项目主页嵌入项目结构概览
- 在每日笔记中嵌入本周任务看板
- 在文档中内联展示系统架构图

## 导入

### 从幕布导入

1. 在幕布中导出为 OPML 格式
2. 在 Obsidian 中打开命令面板，执行「MindDoc: 导入 OPML 文件」
3. 选择导出的 .opml 文件
4. 自动生成 .mind.md 文件并打开

### 从 FreeMind 导入

1. 将 .mm 文件保存到本地
2. 执行「MindDoc: 导入 FreeMind 文件」
3. 选择 .mm 文件

### 导入注意事项

- 导入时 `heading-depth` 默认为 3
- 单根节点的 OPML 会将根作为文件标题
- 多根节点的 OPML 每个顶级节点成为 H2
- OPML 中的 `_note` 属性会保留为节点备注

## 导出

### OPML 导出

执行「MindDoc: 导出为 OPML」，文件保存在源文件同目录下。导出的 OPML 可以被幕布、WorkFlowy 等工具导入。

### JSON 导出

执行「MindDoc: 导出为 JSON」，输出简化的树结构 JSON：

```json
{
  "version": 1,
  "root": {
    "title": "根节点",
    "children": [
      { "title": "子节点", "note": "备注文本" }
    ]
  }
}
```

### PNG 导出

在**脑图视图**下，执行「MindDoc: 导出为 PNG」，会将当前脑图以 2x 分辨率导出为 PNG 图片（浏览器下载）。

> 注意：PNG 导出仅在脑图视图下可用。

### 复制为 AI 上下文

执行「MindDoc: 复制为 AI 上下文」，将当前文档结构化输出到剪贴板，格式适合直接粘贴给 ChatGPT / Claude 等 AI 工具：

```
以下是文档 "项目规划" 的结构化内容：

# 项目规划

## 第一阶段
- 需求调研
- 技术选型

---
格式说明：这是一个 Markdown 树结构文档...
```

## 设置

### 通用

- **默认视图**：打开文件时显示大纲还是脑图
- **默认标题深度**：未在 frontmatter 中指定时使用的 heading-depth

### 大纲

- **字体大小**：大纲视图文字大小（12-20px）
- **显示备注预览**：在节点标题旁显示 note 的首行

### 脑图

- **方向**：左右展开 / 仅向右 / 仅向左

### 性能

- **虚拟滚动**：节点数超过阈值时启用，避免大文件卡顿
- **虚拟滚动阈值**：触发虚拟滚动的节点数（默认 200）

### 编辑

- **自动保存延迟**：编辑后延迟写入文件的毫秒数（默认 300ms）

### 嵌入

- **嵌入块默认高度**：嵌入块不指定 height 时的默认高度

## 文件格式详解

### Frontmatter 字段

```yaml
---
minddoc: true              # 标识为 MindDoc 文件（必需，或使用 .mind.md 后缀）
version: 1                 # 格式版本
default-view: outline      # 打开时的默认视图（outline / mindmap）
heading-depth: 3           # 标题最大深度
---
```

### 节点类型映射

| Markdown 元素 | MindDoc 节点类型 | 说明 |
|---------------|-----------------|------|
| `# 标题` | heading 节点 | 深度由 # 数量决定 |
| `- 列表项` | list-item 节点 | 深度由缩进决定 |
| `1. 有序列表` | list-item (ordered) | 标记为有序 |
| `- [ ] 任务` | list-item (checked=false) | 未完成任务 |
| `- [x] 任务` | list-item (checked=true) | 已完成任务 |
| 段落文本 | node.note | 归属为最近节点的备注 |
| 代码块/引用/表格 | node.blocks | 归属为最近节点的附属内容 |

### 标题跳级

MindDoc 允许标题跳级（如 H1 后直接出现 H3），跳级的标题直接成为上级标题的子节点，不会插入虚拟节点。

### 多个 H1

一个文件中可以有多个 H1 标题，它们作为虚拟根节点的平行子节点存在。

## 常见问题

### Q: 文件可以用其他编辑器打开吗？

可以。MindDoc 文件就是标准 Markdown，任何 Markdown 编辑器、VS Code、甚至 cat 命令都能正常读取和编辑。

### Q: 编辑后会改变我的文件格式吗？

只有你通过 MindDoc 编辑的节点会被重新生成格式。未触碰的内容保持原样，包括空行、缩进等。

### Q: 脑图中拖拽节点，大纲会同步吗？

是的。两个视图共享同一棵 AST，任何编辑操作都会实时同步。切换视图不需要重新加载。

### Q: 支持移动端吗？

支持。MindDoc 标记为 `isDesktopOnly: false`，在 Obsidian 移动端可以使用大纲视图。脑图视图在小屏幕上体验可能受限。

### Q: 文件很大时会卡吗？

MindDoc 对 5000+ 行的文件解析时间 < 500ms。大纲视图在节点数超过 200 时自动启用虚拟滚动。脑图视图在 500+ 节点时可能出现渲染延迟。

### Q: 如何与 Git 配合使用？

非常适合。因为数据是纯文本 Markdown，Git diff 可以清晰显示每次修改了哪些节点。建议开启自动保存并在合适的时机 commit。
