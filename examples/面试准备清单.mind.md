# 面试准备清单

## 算法与数据结构

### 必刷题型

- 数组与哈希
  - 两数之和
  - 三数之和
  - 滑动窗口最大值
- 链表
  - 反转链表
  - 合并 K 个有序链表
  - LRU Cache
- 树与图
  - 二叉树层序遍历
  - 最近公共祖先
  - 拓扑排序
- 动态规划
  - 最长递增子序列
  - 编辑距离
  - 背包问题

### 复习策略

- [ ] 每天 2 题（1 中等 + 1 困难）
- [ ] 按专题刷，不要随机
- [ ] 做完写总结，归纳模板
- [x] 买 LeetCode 会员

## 系统设计

### 高频题目

- 设计短链接服务
- 设计消息队列
- 设计新闻推荐 Feed
- 设计分布式缓存

### 答题框架

- 需求澄清（5 分钟）
  - 功能需求
  - 非功能需求（QPS、延迟、可用性）
- 高层设计（10 分钟）
  - 核心组件
  - 数据流
- 详细设计（20 分钟）
  - 数据库 schema
  - API 设计
  - 关键算法
- 扩展讨论（5 分钟）
  - 瓶颈分析
  - 扩容方案

## 行为面试

### STAR 法则准备

- 领导力
  - 带领团队完成紧急项目
  - 推动技术方案落地
- 冲突处理
  - 与 PM 的需求分歧
  - 代码 review 中的技术争论
- 失败经历
  - 线上事故复盘
  - 项目延期反思

### 反问清单

- 团队目前最大的技术挑战是什么？
- 新人前 3 个月的期望产出？
- 团队的技术决策流程是怎样的？

## 时间表

- [ ] Week 1-2：算法高频题
- [ ] Week 3：系统设计
- [ ] Week 4：行为面试 + 模拟
- [ ] 面试前一天：休息，不刷题
