# 创业公司技术架构

## 基础设施

### 云平台

- AWS
  - EKS（Kubernetes）
  - RDS（PostgreSQL）
  - S3（对象存储）
  - CloudFront（CDN）
- 备选
  - 阿里云（国内业务）
  - Cloudflare（边缘计算）

### 监控告警

- 日志：Loki + Grafana
- 指标：Prometheus + Grafana
- 链路追踪：Jaeger
- 告警：PagerDuty

### CI/CD

- GitHub Actions
  - lint + test（PR 阶段）
  - build + deploy（合入 main）
- ArgoCD（GitOps 部署）
- 环境
  - dev（每次 push 自动部署）
  - staging（每日自动同步 main）
  - production（手动审批）

## 后端

### 技术选型

- 语言：Go 1.22
- 框架：自研（net/http + 中间件）
- ORM：sqlc（SQL 优先）
- 缓存：Redis 7

### 服务划分

- API Gateway
  - 认证鉴权
  - 限流
  - 请求路由
- User Service
- Content Service
- Notification Service
- Payment Service（对接 Stripe）

### 数据库设计原则

- 单库单服务
- 读写分离（超过 5000 QPS 时）
- 慢查询监控 + 自动告警

## 前端

### Web 端

- 框架：Next.js 14（App Router）
- 状态管理：Zustand
- UI 组件：Radix + Tailwind
- 打包：Turbopack

### 移动端

- React Native（Expo）
- 共享 95% 业务逻辑代码
- 原生模块：相机、推送

## 安全

- 认证：Auth0（OAuth 2.0 + OIDC）
- API：JWT + RBAC
- 数据加密：AES-256-GCM（静态）、TLS 1.3（传输）
- 合规：SOC 2 Type II（12 个月内取得）
