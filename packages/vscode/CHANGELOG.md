# Changelog

## 0.1.0 (2026-05-14)

- Initial release
- Outline view with full keyboard navigation
- Mind map view (left-right / right-only / left-only layouts)
- Drag-and-drop reordering in both views
- Search and filter nodes (Ctrl+F)
- Import from OPML and FreeMind formats
- Export to OPML, JSON, and PNG
- Copy as AI Context for LLM workflows
- Native VS Code undo/redo integration
- Theme adaptation (light / dark / high contrast)
- View state persistence per file
